# CITYROLL — демо 0.6

## Запуск
Откройте `index.html` в современном браузере. Интернет нужен только для загрузки шрифта Google Fonts; без него игра тоже работает.

## Что добавлено в 0.3
- Анимация прокрутки и выдача случайной недвижимости.
- Портфель объектов с подтверждением продажи.
- Демо-рынок с покупкой тестовых объектов.
- Ежедневная награда +250 CR.
- Уровни, опыт и улучшение удачи.
- Автосохранение локального прогресса через localStorage.

## Важно
Это клиентский прототип. Рынок пока не является общим рынком игроков: предложения тестовые, а покупки и баланс хранятся только в браузере пользователя. Нельзя использовать такую реализацию для реальной экономики или ценных предметов.

Перед публикацией Telegram Mini App потребуется сервер:
1. Проверка Telegram `initData` на серверной стороне.
2. Серверная генерация RNG и хранение баланса/инвентаря в БД.
3. API для размещения, покупки и снятия объявлений с атомарным списанием средств.
4. Защита от повторных запросов и проверка прав владельца.
5. История сделок и модерация объявлений.

Не храните секреты бота или доверенную игровую логику в клиентском JavaScript.

## Версия 0.6
Сохранены механики демо 0.5 и добавлены цветовые редкости Common / Uncommon / Rare / Epic / Legendary / Mythic / Exclusive, цветные карточки, эффекты трёх высших редкостей и панель бесплатных дуэлей 1 на 1. Прогресс из `cityroll_v05` переносится в `cityroll_v06`; прежняя редкость `unique` отображается как `exclusive`.

Дуэли работают через API и PostgreSQL: игроки входят в очередь, сервер объединяет двух разных игроков, выбирает победителя криптографически случайно и обновляет отдельный рейтинг. Баланс и недвижимость не участвуют и не меняются. Нужны настроенный backend, применённая схема SQL 0.6 и Telegram `initData`. Локальный просмотр без backend сохраняет игру 0.5, но сетевой поиск соперника недоступен.

Это всё ещё демонстрационный игровой проект: локальная экономика, ремонт, офис и рынок 0.5 не стали серверно-авторитетными. Перед публичным запуском потребуется завершить серверную интеграцию этих действий, защиту API, аудит и юридическую проверку.


## Версия 0.5.0
Цветовая тема интерфейса автоматически меняется вместе с выбранной валютой: BTC — золотисто-жёлтая, ETH — фиолетовая, USDT — изумрудно-зелёная.


### Прогрессия CRYPTOROLL 0.6.0
Уровни не ограничены. BTC доступен с 1 уровня, ETH открывается на 50, USDT — на 100. Отдельные модели оборудования и источники энергии постепенно открываются на своих уровнях; до разблокировки их нельзя приобрести.
